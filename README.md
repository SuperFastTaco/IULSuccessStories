# IUL Success Stories

React/Vite website with an Express server for local development and production.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Optional: copy `.env.example` to `.env` and add Meta tracking credentials.
3. Run the app:
   `npm run dev`

Open `http://localhost:3000`.

## Checks

- `npm run lint` — type-check the project
- `npm run build` — create a production build
- `npm start` — serve the production build
